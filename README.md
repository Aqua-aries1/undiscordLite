# UndiscordLite（Vencord 插件）

Undiscord Lite 的 Vencord userplugin 版：批量删除 Discord 消息（搜索筛选 / 批次队列 /
数据导出导入 / 限速与确认），在此之上加了三个本地功能——**一键清理**近期消息、
**自动冲水**、**一键复读**。

入口三选一：聊天区右上角工具栏的垃圾桶图标（与 Message Logger Enhanced 同位置）、
`/undiscord` 命令、热键 **Ctrl+Shift+D**。插件默认启用，令牌自动从 Discord 登录态读取，
无需手动粘贴。

## 安装

需要 **源码构建的 Vencord**（installer 版装不了 userplugin）。把本目录整个放到 Vencord
仓库的 `src/userplugins/undiscordLite`：

```bash
git clone https://github.com/Aqua-aries1/undiscordLite src/userplugins/undiscordLite
pnpm build
```

然后重启 Discord 即生效。

- Vencord：**1.15.x 及以后**（这版是按 1.15.13 的 API 写的；更早的版本里 toast / 弹出菜单的
  调用形态不一样，插件会静默失效而不是报错）。
- 依赖 `MessagePopoverAPI` 这个内置 API 插件（Vencord 会在启用时自动打开）。
- 插件默认启用；不需要填 token，令牌从 Discord 自己的登录态读取。

## 功能

### 一键清理 · 自己的近期消息

面板「Date interval（日期区间）」折叠段内有一行快捷操作：时间窗下拉（近 1 小时 / 6 小时 /
24 小时 / 3 天 / 7 天 / 30 天 / 自定义数值+单位），点「清除我在本服务器的近期消息」＝
自动把 作者=自己、目标=当前打开的服务器（全频道）、日期窗=所选 填好，然后进入正常流程。
**删除前仍然要求确认**，不跳过任何安全闸。私信界面下不可用；时间窗选择会记住。
运行结束后日期筛选自动恢复为「全部时间」——窗口只服务这一次清理。

### 自动冲水

在 Vencord 插件设置页里配置。开启后，作用域内**你自己发送**的消息（含从手机等其它设备
同步过来的）会在延时到达后自动删除。删除时刻 = **消息发出时间 + 延时**，所以从别的设备
迟到同步进来的消息也落在它本该落的那一刻。

**设置项**：总开关（默认关）、延时秒数（默认 60，1–86400）、**频道冲水时长（单独指定）**、
服务器层「自动冲水的服务器」/「不自动冲水的服务器」、频道层「自动冲水的频道」/
「不自动冲水的频道」、**重启后补删欠着的冲水**（默认开）、复读按钮的图标（六选一，另有一个
可覆盖它的自定义输入框）。

**每个频道/子区可以有自己的延时，和全局那个分开存**：

- 优先级 **本频道 → 父频道 → 全局**。给父频道设了，它下面的子区（帖子/主题）一起跟着变；
  某个子区自己设了就只那个子区不同。
- 右键那个频道/子区 →「自动冲水」→「**本频道冲水时长**」，里面是「跟随全局（60 秒）」+ 一串
  常用值（10 秒 / 30 秒 / 1 分钟 / 5 分钟 / 15 分钟 / 30 分钟 / 1 小时 / 6 小时 / 24 小时）+
  一条「自定义」滑块（1 秒 – 1 小时，逐秒可调）。**改这里永远不动全局那个数**。
- 想填滑块范围外的值（比如 2 小时 15 分）：设置页的「频道冲水时长（单独指定）」直接写
  `频道ID:秒`，多个用逗号或空格隔开。菜单和设置页写的是同一个字段。
- 已经在倒计时的消息不会因为改延时而改期——它按当初排的计划删；新延时从下一条消息开始算。

**作用域 = 两层，每层两个名单框，没有"模式"开关**（措辞上刻意说「自动冲水 / 保留」，
不用"白名单/黑名单"，也不用"只冲水"这类说法）：

- **服务器层**——「自动冲水」留空 = 不限制；填了则**只有**列出的服务器会冲，其余（含私信）
  保留。「不自动冲水」列出的永不冲，优先于同层那个。私信在服务器层写 `@me`。
- **频道层**——「不自动冲水」是**绝对的**：列出的频道永不冲，即使服务器层说冲；
  「自动冲水的频道」是**额外加入**：列出的频道一律冲，**即使它所在的服务器被服务器层排除**
  （这就是"只把某一个频道加进自动冲水"）。
- 两层合成：频道在「不自动冲水」→ 不冲；否则频道在「自动冲水的频道」→ 冲；否则交给服务器层。
- **子区（帖子/主题）跟随父频道**：判定时把频道自身和它的父频道都拿去比对，填父频道 = 整棵
  子树一并生效。
- **名单分隔符**：逗号、空格、顿号、全角逗号都行，一行一个也可以（ID 通常是从 Discord 复制
  粘贴来的，形态不由你控制）。写回时一律规范成单个逗号。

**可靠性**：

- 瞬时失败会重试：DELETE 遇网络错误 / 5xx / 429 → 30 秒后重试，最多 20 次；
  401/403/404 视为了结（本来就不该删 / 已被删 / 令牌问题，重试无用）。失败的承诺不会被静默
  丢掉——只有拿到终局结果才会从落盘清单里划掉。
- 重启后补删：待删清单落 localStorage，下次启用时补删（只补 **24 小时以内**的，且按**当前**
  作用域复核——你新加进"不冲水"的频道不会再被删）。
- 防重删 / 防历史风暴：只冲本插件运行期间新产生的消息（频道同步重放的旧消息一律跳过），
  同一条消息的删除承诺只兑现一次。
- 发送卡住（SENDING/FAILED）等约 30 秒后放弃并留日志；403/404 静默。
- 状态可见：每次打开面板都会在日志里打一行，例如
  `自动冲水：开 · 延时 60s（另 2 个频道/子区自定义）· 服务器层：2 个服务器自动冲水，其余保留 · 频道层：额外加入 1 个 · 待删 K 条`；
  关着时是 `自动冲水：关（你发的消息不会被自动删除）`。

**已知边界**：Discord 重启前已经发出的消息不追溯（只冲本插件运行期间发出的）。
一处刻意的不对称：**关掉「自动冲水」开关** = 到点的删除判定为作废（清掉计划）；
而**关掉整个插件** = 计划保留、下次启用继续补。

### 右键快捷菜单（不用手抄 ID）

在频道 / 消息 / 服务器图标上右键 →「**自动冲水**」子菜单。**只有一对动词**：
「**移出自动冲水（消息保留）**」/「**加入自动冲水**」，按**当前真实效果**显示，点一下就是翻转。

- 按层分组：先「`#频道`」（私信显示 `@对方`），再「服务器名」（私信显示「私信（@me）」）。
- 频道行永远可点——给单个频道点「加入自动冲水」就真的把它拉进冲水，即使它所在的服务器被
  服务器层排除。
- 频道那组末尾还有「**本频道冲水时长：X（自定义 / 跟随父频道 / 跟随全局）**」，展开就能给
  这个频道或子区单独换延时，不用动全局那个数（详见上面「自动冲水」）。
- 子菜单末尾一组「**复读模式**」：**「直接发出」/「预填充」**，带圆点显示当前项，点一下即切，
  不用开设置页（写的是同一个设置）。
- 点击后菜单**保持打开**，标签／圆点当场就是新的，不用移动鼠标。
- 写回的是即刻持久化的设置，设置页下次打开就能看到这些 ID。

### 一键复读（消息悬停工具条）

任何消息（自己的和别人的）悬停时都有一个复读按钮，点一下把该消息内容原样再发一条。

- **文本 + 附件**：文本原样搬；附件会**重新上传一份**（Discord 没有"把别人的文件转发出去"
  的发送方式），所以纯附件消息也能复读。被删消息、贴纸/嵌入消息不显示按钮。附件上限按
  Discord 的规矩拦（一条消息最多 10 个附件、单文件 10 MB / Nitro 100 MB），要重传时先弹一个
  进度提示；文本超长同样先拦下并提示。
- **保持你正在回复的那个人**：如果输入框里已有"正在回复至 X"的引用，复读发出去的这条也是
  回复 X，而且不会清掉你输入框里的引用。
- 复读就是**正常发送**：不抑制通知（原文 @ 到的人照常收通知），自动冲水照常生效。
- **防连点**：同一条消息在发出前重复点不会出现两条。
- **没权限就不显示**：服务器频道里没有"发送消息"权限时不显示按钮（DM 不查权限位）。
- **图标六选一 + 可自定义**：⟳ 循环箭头（默认）/ ⧉ 复制方块 / ◟ 回声波纹 / 「复」字 /
  ❝ 引号 / 🦜 鹦鹉。自定义框填了就覆盖上面那项，可填任意 emoji、一两个字，或自己服务器的
  自定义表情写成 `<:名字:id>`（动图 `<a:名字:id>`）。留空即用预设。

**复读模式**（设置页与右键菜单同一项）：

- **直接发出**（默认）：点一下就发出去。
- **预填充**：什么都不发，只把内容摆进编辑器，按回车的权利交给你（可以接着改字）。文字是
  **追加**而不是覆盖，不会吃掉你正在写的字；附件走 Discord 原生的上传预览，所以进度、体积/
  数量提示都用 Discord 的。只对**当前打开的频道**有效——从别的频道的消息上点复读会直接拒绝
  并说明（静默把内容写错地方比报错糟得多）。

### 作者 ID 留空 = 冲所有人（不按作者筛选）

面板里的「作者 ID」留空时，范围内**所有作者**的消息都会被删除（上游版本在 UI 层会把空值
偷偷换成"你自己"，这里去掉了那层替换）。**唯一的硬性拦截是权限**：删别人（或所有人）的消息
需要目标频道/子区的「管理消息」权限，插件会在开跑前预检。私信目标即使作者留空也只按本人
处理（Discord 不允许删别人的私信消息）。

> 四个名单只管「自动冲水」，**不影响**面板里的手动清理——手动清理按你填的搜索条件删，
> 是明确的动作，不该被别处的名单悄悄削掉范围。
